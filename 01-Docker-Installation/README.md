# 01 — Docker Installation

This section helps you install Docker and verify that the Docker CLI can communicate with the Docker Engine.

| Operating system | Installation guide |
|---|---|
| Windows 10/11 | [windows.md](windows.md) |

Always check the current official requirements before installing. Docker Desktop and Docker Engine have different installation procedures.

## After installation

Follow [installation-verification.md](installation-verification.md) to verify Docker and run your first container.

## Important terminology

- **Docker Desktop:** Desktop application for Windows and macOS that provides Docker Engine and developer tools.
- **Docker Engine:** The server-side runtime that builds and runs containers.
- **Docker CLI:** The `docker` command used to communicate with the Engine.
- **Docker Compose:** Tool for defining and running multi-container applications.
